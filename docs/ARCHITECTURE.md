# 实现结构与验证

[返回首页](../README.md)

## 文件结构

| 文件 | 责任 |
|---|---|
| `organizer.py` | 根目录扫描、规则分类、文件身份校验、事务移动、撤销恢复与 Tkinter 窗口 |
| `web_app.py` | 回环 HTTP 服务、请求授权、预览计划与 Web 页面；复用同一文件操作核心 |
| `reset_demo.py` | 只补齐已知合成样本，保留未知/修改过的文件 |
| `run_demo.bat` / `reset_demo.bat` | 选择 Python 入口并保持退出码，支持含空格路径 |
| `tests/` | 独立临时输入、状态、进程及 HTTP/GUI 回归 |
| `.github/workflows/windows-tests.yml` | Windows / Python 3.10、3.11、3.12 矩阵；官方 Actions 固定提交 |

## 一次文件操作

1. 扫描得到预览记录：源、目标、分类、匹配分、警告及文件指纹。
2. 用户确认后，锁定事务并重新检查路径、目标冲突和源文件是否变化。
3. 移动前持久化意图，采用 Windows 非覆盖重命名并逐步更新日志。
4. 普通失败尝试回滚；无法完成恢复时保留状态并明确提示。
5. 撤销时先验证日志边界、文件身份与完整内容，再恢复原位置。未完成恢复的事务会阻止新整理。

Web 入口额外要求同源、请求令牌、显式确认及与根目录绑定的限时一次性计划；有请求体、超时和并发限制，不适合公网部署。

## 验证方式

- 内容变化与目标竞争：检查实际源/目标文件，不仅检查函数返回值。
- 崩溃恢复：独立子进程在文件操作后退出，再重新读取记录恢复。
- GUI：临时数据、确认取消、预览快照、后台任务与撤销后刷新。
- HTTP：真实回环请求，覆盖授权、计划失效、异常请求体及失败不移动文件。
- 启动：临时解释器和中文/空格路径，验证应用失败不会再次执行。

历史基线为每个 CI Python 版本 63 项测试，详细结果以[实际 Actions 日志](https://github.com/mmm-05-aaa/desktop-file-organizer/actions)为准。测试成功不是分类准确率，也不代表不存在未知缺陷。

## 明确不做的承诺

不将本工具描述为备份系统，不承诺网络盘/云同步兼容、物理断电恢复或跨平台支持。可选 PDF 内容解析须单独集成验证后才能宣传其效果。
